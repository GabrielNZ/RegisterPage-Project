# 👤 RegisterPage Project
[![NPM](https://img.shields.io/npm/l/react)](https://github.com/GabrielNZ/FinalProject-AppAgendamento/blob/main/LICENSE)

## Estrutura do Projeto

A user registration page where users can register their Name, Email, CPF, Date of Birth, State, and Municipality.

I decided to create a project based on a simple idea (User CRUD), but take it to a professional level, incorporating features commonly found in professional software, such as dynamic APIs, input masks, search functionality, and more.

A purely frontend Angular project, with no custom backend, using LocalStorage to store its data.

## 📃 Features:
- Complete user CRUD
- States and municipalities retrieved via API using HttpService
- Dynamic municipalities based on the selected state
- Dynamic routes with parameters
- User search by name
- Dynamic input masks for fields such as CPF and Date of Birth
